# Example projects / 示例项目

Import any `.figurelab.json` file through **导入项目**. Every module and connection remains editable.

| File stem | Purpose | Provenance |
| --- | --- | --- |
| research-workflow | Scientific question to reporting | Built-in illustrative workflow |
| study-design | Control and intervention branches | Authored illustrative study structure |
| model-architecture | Parallel local/global feature branches | Authored illustrative model structure |
| ai-material-defect | Material-defect research workflow | Real provider output from the walkthrough, followed by manual label/color edits and layout |

Each project is accompanied by native SVG and white-background PNG exports. The three starter examples contain no real experimental data. The walkthrough example uses a non-sensitive illustrative description and does not claim experimental results.

示例用于展示流程与模块组织方式，不代表经过验证的实验方案或科学结论。导入后可逐个编辑模块、文字与连接。
