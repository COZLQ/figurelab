# FigureLab v0.1.0

Release notes prepared for the first public version.

FigureLab turns research descriptions into editable workflow, study-design, and model-architecture diagrams. Generated output is reviewed before it is applied to the canvas.

## Included

- Text-to-diagram with DeepSeek and Chat Completions-compatible providers.
- Pan/zoom preview, uncertainty notes, cancellation, and recoverable generation errors.
- Editable text, modules, styles, dimensions, connections, and undo history.
- Browser autosave, project JSON round trips, native SVG and PNG exports.
- Three starter examples, English/Chinese documentation, and an application walkthrough.

## Validation

Local type checks, 48 automated tests, browser workflows, production build, and one real-provider generation have passed. Publication-file checks and a clean-checkout smoke test accompany the release candidate.

## Known limits

This version is designed for local or private use. Accounts, cloud storage, and public-service access control are not included. Authors must verify scientific content. Cross-device SVG text depends on fonts, and external vector editor compatibility is not exhaustively tested.
