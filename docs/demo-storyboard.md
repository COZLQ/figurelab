# Application walkthrough

The published GIF and MP4 are a 27-second key-step edit of actual FigureLab captures. The provider waiting scene is shortened; this is not a real-time latency benchmark.

| Scene | Actual action |
| --- | --- |
| Describe | Enter a four-step illustrative material-defect research description |
| Generate | Make one real DeepSeek request with operator-provided credentials |
| Review | Check generated modules, connections, and author-review notes |
| Expand | Open the larger preview and fit the complete graph |
| Apply | Place the candidate on the editable canvas |
| Move | Drag a module and observe the connected arrows |
| Customize | Edit a label and choose a different color |
| Arrange | Run horizontal automatic layout |
| Export | Download native SVG; project JSON and PNG are also saved |

Credentials are collapsed out of the capture. The original canvas was backed up before the walkthrough and restored afterwards; its saved fields were compared with the backup. The recording's editable result is [ai-material-defect.figurelab.json](../examples/ai-material-defect.figurelab.json).

The video has no narration. English and Chinese chapter captions describe each actual step. No user identity, private project path, or unmasked key is included in the public frames.
