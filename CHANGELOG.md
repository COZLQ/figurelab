# Changelog

## v0.1.0 — release candidate

### Added

- Local-first scientific diagram canvas with templates for workflows, study designs, and model architectures.
- Editable labels, shapes, colors, sizes, and connections; undo and redo.
- Browser autosave and downloadable/importable project JSON.
- Native SVG export and white-background PNG export.
- DeepSeek / Chat Completions-compatible text-to-diagram generation.
- Structural validation, author-review notes, and explicit apply-to-canvas.
- Readable preview with zoom, pan, fit, actual size, and expanded viewing.
- Request cancellation, actual waiting time, error actions, and retention of earlier successful previews.
- English and Chinese project documentation, examples, demonstration media, and contribution templates.
- GitHub Actions workflow for type checks, tests, release-file checks, and production build.

### Known limits

- No built-in accounts, cloud storage, or public-service access control.
- AI content requires scientific review; one generation is capped at 20 modules and 45 edges.
- Font availability can affect SVG text on another device.
- Third-party vector editor compatibility has not been exhaustively tested.

This entry describes the prepared candidate; no GitHub release has been published yet.
